Advanced: load a TensorFlow.js model instead
If loaded, the model receives the same feature vector as a flat tensor (order shown below the feature table) and its argmax over 4 outputs (Idle, Fidgeting, Gripping, Writing) is used instead of the JS function above. Falls back to the JS classifier if loading fails.
Advanced: load an ONNX TCN model instead (raw sequence input)
This model takes the raw windowed time series — not the aggregated feature vector above — resampled to the sequence length as a [1, 6, seq_len] tensor in channel order ax, ay, az, gx, gy, gz (matches a TCN's dilated causal convolutions). Its argmax over 4 outputs (Idle, Fidgeting, Gripping, Writing) is used, with softmax as the confidence readout. Takes priority over the TFJS/JS classifiers above when loaded; falls back to them if loading or inference fails.
